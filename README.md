Experiment 8 — Matched Filtering, ISI and Eye Diagrams

This experiment demonstrates matched-filter reception, noise effects, timing sensitivity, and inter-symbol interference (ISI) using BPSK and RRC pulse shaping.

Topics Covered
BPSK transmission with RRC pulse shaping
Matched-filter reception
AWGN and SNR variation
Eye diagrams
Eye height versus SNR
BER versus timing offset
Multipath channel and ISI
Total filter-delay compensation
